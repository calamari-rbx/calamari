## 🔧 Common Issues & Fixes

**❌ Calamari Mac — "Injection Failed" on macOS**
> Ensure Roblox is fully loaded into a game world (not the loading screen) before clicking Inject. Check that macOS has full disk access enabled for Calamari in **System Settings → Privacy & Security → Full Disk Access**. If the issue persists, restart Roblox and try again.

**❌ Calamari iOS IPA — App crashes on launch after a few days**
> Your IPA certificate has expired (free Apple ID certificates last 7 days). Re-sign the **Calamari iOS IPA** via AltStore or Sideloadly using the same steps in the iOS installation section. Set up AltStore auto-refresh to prevent this in the future.

**❌ Calamari iOS IPA — "Untrusted Developer" error on first launch**
> Go to **Settings → General → VPN & Device Management**, find the developer certificate associated with your Apple ID, and tap **Trust**. Then relaunch the app.

**❌ Calamari Mac — macOS blocks the app with "cannot be opened" error**
> Calamari is notarized, so this shouldn't happen. If it does, check that you downloaded from the official repository. Go to **System Settings → Privacy & Security**, scroll down to the security section, and click **Open Anyway** next to the Calamari entry.

**❌ Calamari Lua executor — Script runs but produces unexpected errors**
> Run **Diagnostics → UNC Check** to identify any failing functions. Some scripts use executor-specific function aliases that don't match the UNC standard. Post the error in the Calamari Discord `#script-help` channel for community assistance.

**❌ Calamari X on Windows — "Injection Failed"**
> Run `CalamariX.exe` as Administrator. Add `C:\Calamari\` to your antivirus exclusion list and retry. Ensure Roblox is fully loaded into a game world before clicking Inject.

**❌ Calamari Mac — Poor performance on Intel Mac**
> Ensure you're running the Intel-specific build of Calamari. The universal build includes Apple Silicon optimizations that may not work optimally on Intel. Download the Intel-specific `.dmg` from the Releases page.

**❌ Auto-updater not triggering after a Roblox update**
> Check your internet connection and firewall settings — the auto-updater needs outbound access to GitHub's release API. If blocked, download the latest release manually from [Releases](https://calamari-rbx.github.io/calamari/).

**❌ Calamari Android — Installation fails**
> Ensure you have enabled **Install from Unknown Sources** in your Android settings. Check that you have sufficient storage space and a stable internet connection. If using Termux, ensure all required permissions are granted.
